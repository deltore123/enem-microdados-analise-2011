
# Análise dos Microdados do ENEM 2011

## Sobre o projeto

Este projeto realiza uma análise exploratória dos microdados do ENEM 2011 com o objetivo de investigar possíveis relações entre características socioeconômicas e o desempenho dos candidatos.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Fonte dos dados

Microdados do ENEM 2011 disponibilizados pelo INEP.

## Principais análises

- Distribuição das notas
- Comparação entre áreas do conhecimento
- Análise por sexo
- Análise por raça/cor
- Escola pública vs privada
- Escolaridade dos pais
- Perfil da elite de desempenho

## Estrutura do projeto

- Limpeza e preparação dos dados
- Tradução das variáveis categóricas
- Análise exploratória dos dados
- Principais achados
- Conclusão

## Como executar

1. Baixe os microdados do ENEM 2011.
2. Armazene o arquivo CSV no Google Drive.
3. Ajuste o caminho da variável `path` no notebook.
4. Execute o notebook no Google Colab.
